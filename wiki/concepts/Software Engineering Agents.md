# Software Engineering Agents (軟體工程代理人)

## 1. 概念定義
**Software Engineering Agents（軟體工程代理人）** 指能夠在真實複雜代碼庫中，自主執行 Issue 閱讀理解、代碼檢索、Bug 定位、編寫代碼修復 Patch、執行測試並交付合格 Pull Request 的自主 AI 系統。

## 2. 演進里程碑
1. **單一函式補全時代**：GitHub Copilot、[[HumanEval]]。
2. **基於提示與終端互動**：Devin、SWE-agent。
3. **基準驗證與工業落地**：[[Jimenez2024-SWEbench]] 確立了以真實專案回歸測試作為評判 Agent 能力的黃金標準。
