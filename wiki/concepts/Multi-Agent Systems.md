# Multi-Agent Systems (多代理人系統)

## 1. 概念定義
**Multi-Agent Systems（多代理人系統）** 指由多個具備自主決策、不同角色分工（Role-playing）或環境感知能力的 Agent 組成的分散式協同網絡。

## 2. 應用範式
1. **社會模擬 (Social Simulation)**：如 [[Park2023-GenerativeAgents]] 模擬小鎮居民的資訊擴散與社交組織。
2. **軟體工程與任務協同**：如 ChatDev、MetaGPT 讓多個 Agent 扮演產品經理、架構師、工程師與測試員，透過對話推進複雜項目完成。
